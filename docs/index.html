GeoUniPS leverages geometric priors from large-scale 3D reconstruction models to improve universal photometric stereo under limited lighting cues.

Abstract

We present GeoUniPS, a universal photometric stereo network that integrates synthetic supervision with high-level geometric priors from large-scale 3D reconstruction models pretrained on massive in-the-wild data. Our key insight is that these 3D reconstruction models act as visual geometry foundation models, inherently encoding rich geometric knowledge of real scenes.

GeoUniPS delivers state-of-the-art performance across multiple datasets, both quantitatively and qualitatively, with notable robustness in complex in-the-wild environments.

Quick Start

git clone https://github.com/marcotam2002/geounips.git
cd geounips

conda create -n geounips python=3.10.19
conda activate geounips

pip install torch==2.4.1+cu121 torchvision==0.19.1+cu121 torchaudio==2.4.1+cu121 --index-url https://download.pytorch.org/whl/cu121
pip install einops
pip install opencv-python

python geo_unips/main.py --session_name "test_data" --test_dir "assets" --checkpoint checkpoint --max_image_num 4 --max_image_res 512 --scalable
